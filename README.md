# Voice Control Assistant for Windows

A lightweight voice-controlled assistant for Windows that converts spoken voice commands into local system actions with active learning and persistence.

## Features
- **Speech Recognition**: Listens to microphone input and converts speech to text.
- **Customizable Command Actions**: Easily mapped to open applications, execute system commands, or launch scripts.
- **Self-Correcting Training Loop**: Learns from corrections and persists mappings in commands.json.
- **Text-to-Speech Feedback**: Provides voice and audio confirmations using pyttsx3.

## Installation and Setup

1. Install requirements:
   pip install -r requirements.txt

2. Run the assistant:
   python app.py
